Industry 4.0 mobile manipulator

Rakshith's MEng capstone project, which won the capstone award. A Universal Robots UR-10 collaborative arm sits on an Omron LD250 autonomous mobile base, with a SmartShift tool changer for different end effectors.

Mobile manipulationTool changingSystems integrationFusion 360

What

A mobile manipulator for Industry 4.0. A custom frame holds the power distribution and the robot controller. The SmartShift tool changer replaces the end effectors automatically, so one robot can change its tools and do different tasks on the same factory floor.

How

Rakshith defined the requirements with a senior packaging automation director at Walkers, from the live workflow of the crisp factory in Leicester. Rakshith completed the full mechanical design in Fusion 360, then assembled the arm, base, frame, power systems and tool changer. Three tasks set the specification:

  • Reload seasoning on the flavouring line
  • Put packed cases on pallets
  • Move a leak-detection effector above the oil fryers

Results

The system is new and its technology readiness level (TRL) is low, so it was not approved for a live production line. Rakshith tested the pick-and-place function on a conveyor rig with the full system: arm, base and tool changer. The project won the capstone award.
